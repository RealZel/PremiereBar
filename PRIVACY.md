# Premiere Bar privacy notice

Premiere Bar stores your selected channel, API key, and view goal in its settings on your BUSY Bar. For a configured channel, it sends the channel identifier, API key, upload playlist ID, and public video IDs to Google over HTTPS to retrieve public channel and video statistics from YouTube Data API. Google also receives the network information needed to respond, such as the source IP address. Demo mode uses sample data bundled with the app.

The app keeps the latest public channel and video metadata and statistics on the device for up to 24 hours of use. The cache includes recent view count samples so the app can show the change over roughly one hour. Expired data is cleared while the app is open or when it next starts. To clear the local cache, remove the channel or API key from app settings and restart Premiere Bar. This clears the device copy only.
